# StudyAlcove

*A little place to focus, together.*

StudyAlcove is a planned cozy, browser-based multiplayer study space. Join a room, find a desk, and spend focused time alongside other people in a quiet pixel-art world.

## The experience

StudyAlcove is designed to make studying together feel simple and welcoming. The initial experience aims to let guests:

- Join a shared room and choose an avatar.
- Move around the room and settle into an available seat.
- Start a focus timer while seeing others in the room.
- Return to a record of completed study sessions.
