# StudyAlcove

StudyAlcove is a planned cozy multiplayer pixel-art study room. Guests will be able to join a room, choose a desk and focus alongside other people.

The [roadmap](docs/roadmap.md) describes the planned architecture and milestones. [AGENTS.md](AGENTS.md) contains the project workflow and coding conventions. The project is backend-first; the playable frontend is planned for a later milestone.

Artwork and design explorations are kept locally in `art/` and `docs/design/` and are not included in the repository. Those folders may not exist in a fresh checkout.
